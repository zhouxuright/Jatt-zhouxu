# 生成式人工智能服务备案指南

## 一、备案要求概述

根据《生成式人工智能服务管理暂行办法》(2023年8月15日施行)，提供生成式 AI 服务的企业需完成以下合规工作：

### 1.1 适用范围
- 利用生成式 AI 技术向中国境内公众提供服务的组织
- 包括但不限于：法律咨询 AI、合同审查 AI、文书生成 AI

### 1.2 备案机构
- 国家互联网信息办公室（国家网信办）
- 通过"互联网信息服务算法备案系统"进行备案

## 二、本项目合规清单

### 2.1 算法备案 ✅ 待完成

**需提交材料：**
1. 算法基本信息（名称、类型、应用领域）
2. 算法自评估报告
3. 拟公示信息
4. 算法安全管理制度

**算法信息：**
- 名称：法律智能助手系统
- 类型：生成合成类 — 文本生成
- 应用领域：法律服务
- 基础模型：DeepSeek / OpenAI GPT-4o
- 微调模型：无（当前使用 API 调用）
- 训练数据：公开法律法规数据库

### 2.2 安全评估 ✅ 待完成

**需完成的评估项目：**
1. **语料安全评估**
   - 语料来源合法性证明（laws.json 来自国家法规数据库，合法公开）
   - 语料质量评估报告
   - 语料标注规范

2. **模型安全评估**
   - 模型能力评估（准确性、可靠性）
   - 模型安全性测试（对抗测试、红队测试）
   - 幻觉率测试

3. **安全措施评估**
   - 内容安全过滤机制（已实现 ContentSafetyFilter）
   - 用户输入检测
   - 输出内容审核
   - 个人信息保护

### 2.3 用户权益保护 ✅ 已完成

| 项目 | 状态 | 说明 |
|------|------|------|
| 用户协议 | ✅ 已实现 | UserAgreement.vue |
| 隐私政策 | ✅ 已实现 | PrivacyPolicy.vue |
| 算法公示 | ✅ 已实现 | 聊天页面免责声明 |
| 投诉渠道 | ✅ 已实现 | 反馈系统 |
| 账号注销 | ⚠️ 待实现 | 需添加用户注销功能 |

## 三、具体行动项

### Phase 1: 即时合规（上线前必须）
- [ ] 完善算法备案申请材料
- [ ] 编写算法安全自评估报告
- [ ] 建立内容安全管理制度文档
- [ ] 实现用户账号注销功能
- [ ] 建立用户投诉处理机制

### Phase 2: 持续合规（运营中）
- [ ] 每季度进行安全评估
- [ ] 建立日志留存机制（至少 6 个月）
- [ ] 定期更新用户协议和隐私政策
- [ ] 建立应急响应预案

### Phase 3: 深度合规（长期）
- [ ] 模型安全红队测试
- [ ] 第三方安全审计
- [ ] 数据保护影响评估（DPIA）
- [ ] 算法公平性评估
