# 系统架构文档

## 系统概览

法律智能助手系统（Legal Intelligent Assistance System）是一个基于 AI 大模型的中国法律智能服务平台，采用前后端分离架构，通过多智能体协作、RAG（检索增强生成）和工具调用等技术，提供法律咨询、合同审查、文书生成、法规与案例检索等智能化法律服务。系统支持单机私有化部署，确保数据安全与隐私保护。

## 后端模块

### API 层 (API Layer)

API 层负责处理 HTTP 请求，提供 RESTful 接口：

- **认证授权**：JWT Token 认证、权限控制
- **请求验证**：参数校验、数据验证
- **异常处理**：统一异常响应格式
- **限流控制**：基于 Redis 的请求限流
- **审计日志**：记录 API 调用日志

主要模块：
- `/api/v1/chat` - 智能对话接口
- `/api/v1/contract` - 合同审查接口
- `/api/v1/document` - 文书生成接口
- `/api/v1/law` - 法规检索接口
- `/api/v1/case` - 案例检索接口
- `/api/v1/agent` - 智能体管理接口

### 智能体层 (Agent Layer)

基于 LangGraph 构建的多智能体协作系统：

- **Supervisor Agent**：智能路由，根据用户意图分发任务
- **Contract Agent**：合同审查与分析
- **Document Agent**：法律文书生成
- **Search Agent**：法规与案例检索
- **Compliance Agent**：合规性检查
- 其他专业智能体（共 14 个）

协作模式：
- 单智能体处理：简单任务直接处理
- 多智能体协作：复杂任务由 Supervisor 编排多个智能体协同完成

### RAG 层 (RAG Layer)

检索增强生成核心模块：

- **查询理解**：意图识别、查询改写
- **混合检索**：语义检索（Milvus）+ 关键词检索（Elasticsearch）
- **引用溯源**：为每个引用标注来源与置信度
- **置信度评估**：基于相关度、时效性、权威性评估
- **核验闸门**：低置信度内容过滤，确保引用质量

### 服务层 (Service Layer)

业务逻辑与数据访问：

- **PostgreSQL**：结构化数据存储（用户、文档、配置等）
- **Milvus**：向量存储与语义检索
- **Redis**：缓存、会话、限流、语义缓存
- **Elasticsearch**：全文检索与混合检索
- **Neo4j**：知识图谱（法规关系、案例关联）

### 数据层 (Data Layer)

法律数据资产：

- **法律法规库**：宪法、刑法、民法典等部门法
- **案例库**：裁判文书、典型案例
- **合同模板库**：各类合同模板
- **文书模板库**：诉状、答辩状等模板
- **知识库**：法律常识、实务指南

## 数据流

### 智能对话流程

```
用户请求
  │
  ▼
┌──────────────┐
│   Vue 前端    │ → 发送 HTTP 请求
└──────────────┘
  │
  ▼
┌──────────────┐
│  FastAPI 网关  │ → 认证、限流、路由
└──────────────┘
  │
  ▼
┌──────────────┐
│ Supervisor   │ → 意图识别、智能体选择
│   Agent      │
└──────────────┘
  │
  ▼
┌──────────────┐
│  专业智能体    │ → 任务执行（合同审查/文书生成/检索等）
└──────────────┘
  │
  ▼
┌──────────────┐
│   RAG 检索    │ → 混合检索、引用溯源
└──────────────┘
  │
  ▼
┌──────────────┐
│   LLM 生成    │ → 基于检索结果生成回答
└──────────────┘
  │
  ▼
┌──────────────┐
│   流式响应    │ → SSE 实时推送至前端
└──────────────┘
  │
  ▼
┌──────────────┐
│   用户展示    │ → 实时显示对话内容
└──────────────┘
```

### 关键设计

1. **流式响应**：使用 SSE（Server-Sent Events）实现实时对话，提升用户体验
2. **引用可溯源**：每个引用标注来源、置信度，支持核验
3. **多智能体协作**：复杂任务由 Supervisor 编排多个智能体协同处理
4. **混合检索**：语义检索 + 关键词检索，提升召回率与准确率

## 部署架构

### 开发环境

```bash
docker compose up -d
```

单实例部署，适合本地开发与测试。

### 生产环境

```bash
docker compose -f docker-compose.prod.yml up -d
```

高可用部署：
- 3 个后端实例（负载均衡）
- 资源限制（CPU、内存）
- 健康检查与自动重启
- 数据持久化卷

### 容器编排

| 服务 | 容器名 | 端口 | 说明 |
|------|--------|------|------|
| PostgreSQL | legal_postgres | 5432 | 关系数据库 |
| Redis | legal_redis | 6379 | 缓存与会话 |
| Milvus | legal_milvus | 19530 | 向量数据库 |
| Elasticsearch | legal_es | 9200 | 全文检索 |
| Neo4j | legal_neo4j | 7474 | 图数据库 |
| Backend | legal_backend | 8000 | FastAPI 应用 |
| Frontend | legal_frontend | 80 | Vue 前端（Nginx） |

### 资源需求

- **最小配置**：4 核 CPU, 8GB RAM, 50GB 磁盘
- **推荐配置**：8 核 CPU, 16GB RAM, 100GB SSD
- **生产环境**：16 核 CPU, 32GB RAM, 200GB SSD

## 安全设计

- **数据加密**：字段级敏感数据加密
- **多租户隔离**：数据逻辑隔离
- **AIGC 合规**：内容审核、水印、合规过滤
- **API 限流**：防止滥用
- **审计日志**：操作记录可追溯

## 扩展性设计

- **微服务化**：各模块独立，可拆分部署
- **水平扩展**：后端支持多实例部署
- **插件化**：智能体与工具支持插件扩展
- **数据飞轮**：用户反馈持续优化模型
